## Texto para validação (versão resumida)

**DEM-36 (cliente fica "Em Teste" após vencer)**
- 🤖 **Robô de hora em hora:** atualiza sozinho quem venceu → "Teste Expirado".
- ⚡ **Correção na hora:** ao abrir a tela, o status já é atualizado (sem esperar o robô).
- 🚫 **Bloqueia nova autenticação:** instância vencida não conecta mais (QRCode travado).
- ⏸️ **Instância "Pausada":** aparece pausada com o motivo, botões "Autenticar/Reiniciar" bloqueados.
- 🧱 **Não deixa criar instâncias:** cliente vencido não contrata novas (base: DEM-48, já em revisão).

**DEM-37 (cliente fica "Ativo" após vencer, com teste estendido)**
- 🗓️ **Botão "Estender Teste":** admin prorroga a data sem virar "Ativo".
- ⏰ **Vencimento automático:** passou da data, vira "Teste Expirado" sozinho.
- ✅ **Datas iguais:** admin e cliente veem a mesma data de vencimento.

**Garantias (ambas)**
- 🎯 **Corte na data certa:** API usa a data oficial da assinatura (corrige checagem aproximada/congelada).
- 🔔 **Aviso no painel:** "regularize para continuar".
- 🟢 **Cliente em dia:** nada muda.

**Opcional (Fase 2)**
- 🔌 **Pausa real:** desliga a instância do vencido no servidor e religa sozinho ao regularizar.

## Escopo técnico de referência (para a equipe)
- **manager-service:** transição lazy de `ACTIVE` vencido → `OVERDUE`; cron de expiração (`instrumentation.ts`); ação "Estender Trial" no admin (preserva `TRIAL`); correção do desconto de carência em TRIAL nas rotas admin; bloqueios de UI (autenticar/reiniciar, banner "Ativo vencido", instância "Pausada").
- **api-service:** `validateUser` usando `expiresIn` + status (em vez de `lastContractUpdate + 30`); correção da data congelada no boot (`currentDate` → `new Date()`); `assertCanCreateInstance` com checagem de data; validação de billing nas rotas de restart/resume.
- **Fase 2 (opcional):** pausa real do deployment por vencimento (acionar `pauseInstance`) + resume automático ao regularizar.

## Critérios de aceite
- [ ] Teste vencido → "Teste Expirado", sem criar instância, sem autenticar, instância "Pausada".
- [ ] Teste estendido → continua "Em teste"; ao vencer, vira "Teste Expirado" sozinho.
- [ ] Assinatura paga vencida → "Vencido" + mesmos bloqueios.
- [ ] Cliente em dia → nenhuma mudança.
- [ ] Admin e cliente veem a mesma data de vencimento.
