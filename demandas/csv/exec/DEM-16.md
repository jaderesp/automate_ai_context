# 🚀 Histórico de Execução: Exibe vencimento errado assim que a assiantura é ajustada pelo admin

## 📌 Resumo do Problema
Ao informar uma nova data de vencimentio para a assinatura, a mesma não é exibida corretamnete para o usuário. A data exibida é proveniente desse cálculo: Data Vencimento Informada - Dias de Tolerância - 1 dia. O Adequado é o usuário ver a mesma data de vencimento que o admin informou na edição da assinatura. O INTUITO DA LOGICA É JUSTAMENTE ESSE , O USUARIO NAO PODE VER NEM SEQUER SABER QUE EXISTE ESSE PRAZO DE TOLERANCIA, NAO PODEMOS APRESENTAR PARA O USUARIO A DATA DE VENCIMENTO CONSIDERANDO OS DIAS DE TOLERANCIA. SAO DOIS CONCEITOS DIFERENTES DATA DE VENCIMENTO E DATA DE CORTE.

DE FATO, NÃO É PARA MOSTRAR A DATA DE CORTE PARA O USUÁRIO. A QUESTÃO É QUE QUANDO O ADMIN COLOCA A DATA DE VENCIMENTO, ELE É OBRIGADO A CONSIDERAR + 8 DIAS NA DATA DE VENCIMENTO A SER INSERIDA PARA QUE EXIBA A DATA DE VENCIMENTO CORRETA PARA O USUÁRIO. O OBJETIVO DA CORREÇÃO DESSE BUG É FAZER COM QUE O ADMIN COLOQUE DE FATO A DATA DE VENCIMENTO E A DATA DE CORTE SEJA AUTOMATICAMNETE ATRIBUIDA A DATA DE VENCIMENTO FINAL. OU ENTÃO, NÃO FAZER ESSA ATRIBUIÇÃO AUTOMATICA, SIMPLESMNETE EXIBIR AO USUÁRIO A MESMA DATA DE VENCIMENTO QUE O ADMIN COLOCOU E A DATA DE CORTE SER REALIZADA NORMALMNETE. SEM QUE O USUÁRIO SAIBA.

ESTÁ QUASE QUE CORRIDO. SÓ ESTÁ DEDUZINDO -1 DIA NA DATA INFORMADA PELO ADMIN. EXEMPLO: SE O ADMIN DEFINIR O VENCIMENTO: 01/12/2026 E SALVAR, O VENCIMENTO DA ASSINATURA DO USUÁRIO FICA COMO 30/11/2026.

ALÉM DO MAIS, O ALTERAR VENCIMENTO DA ASSIANTURA PELO ADMIN, DEVERIA TAMBÉM ALTERAR NA ASSIANTURA DO CLIENTE NO ASAAS. CASO ISSO DÊ TRABALLHO DE FAZER, A OUTRA ALTERNATIVA SERIA A ASSIANTURA DO CLIENTE SER EXCLUÍDA NO ASAAS ASSIM QUE O ADMIN ALTERAR A DATA DE VENCIMENTO. ASSIM, O USUÁRIO SERIA OBRIGADO A FAZE RUMA NOVA ASSIANTURA QUANDO EXPIRAR SUA ASSIANTURA NA UZAPI (DEFINIDA PELO ADMIN).


### Teste Prático e Homologação
Correção do shift de Timezone (UTC) efetuada, parseando as datas para T12:00:00Z para evitar regressão de 1 dia.
